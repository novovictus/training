# CompTIA SecAI+ Training Project

This repository is the archived predecessor of the generalized [Training Engine](https://github.com/novovictus/training-engine).

## Project status

Development of this repository by the original author concluded on September 3, 2026. The repository is preserved as a historical snapshot of the independently developed SecAI+ CY0-001 study and assessment project.

The former GitHub Pages application at `https://ninja-neer.net/training/` has been retired. The historical URL is retained only as a redirect to the current Training Engine:

https://ninja-neer.net/training-engine/

The repository was temporarily unarchived on September 21, 2026 to retire the legacy Pages application cleanly, preserve historical inbound links with the redirect, and move the complete prior implementation under `archive/`. No legacy application code is served from the repository root.

## Historical implementation

The complete former functional tree is preserved under:

`archive/`

That directory contains the previous root entry point, practice-test application, question banks, project documentation, and supporting files as they existed before retirement.

To inspect or run the historical implementation, use the files under `archive/` rather than the repository-root redirect.

## Current project

Current development lives at:
